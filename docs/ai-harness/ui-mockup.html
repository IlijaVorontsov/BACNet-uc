Phone · agent first, for the technician on site

Built for one hand, at the valve

  1. The agent drives the checklist. It forces an output under a 60 s lease and asks a question you answer with one tap. Every force is released automatically, even if the phone loses signal.
  2. Approvals are a bottom sheet with a per-device summary. Commit-tier changes need a 1.5 s hold, so a pocket tap cannot apply a plan.
  3. Field tools use what the phone has. Scan the QR label to open a board, make it blink to find it in a ceiling void, or photograph a nameplate for the vision model (glm-5.3-flash) to read.
  4. The run lives on the gateway, not the phone. Close the app mid-checkout, open the desktop, and the same run continues from the same step.
