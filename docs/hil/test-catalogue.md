# HIL test catalogue

Generated from design v2.1 (see [HIL.md](../HIL.md) §9). IDs are stable across the design, the firmware contract and the test files in `hil/tests/`.

Tiers: **release** = unmodified release artifact (plus the D24 site allowlist); **instrumented** = `-S hil` images; **rig** = rig self-tests; **sil** = native_sim / stand-ins.
